Configuration and connection status

AngelOne Connection
Automatic Connection Management
AngelOne connection is established automatically when you log in and disconnected when you log out.

Connection to AngelOne SmartAPI is handled automatically during login/logout.

Order Mode
DRY RUN LIVE

Orders are simulated. No real trades will be executed. Orders are LIVE. Real trades will be executed with real money!

To change this, set order.dry-run in application.yml or environment variable ORDER_DRY_RUN.

UI Login Credentials
Checking... No Credentials Not Authenticated
Get this from AngelOne SmartAPI → Enable TOTP
Note: UI login must be enabled in application.yml by setting angelone.enable-ui-login: true.
API Endpoints
Endpoint Method Description
/api/connection/connect POST Authenticate with AngelOne SmartAPI
/api/connection/status GET Check connection status
/api/connection/disconnect POST Clear session and disconnect
/api/market/candles GET Fetch OHLCV candle data
/api/market/options GET Fetch option chain data
/api/analysis/basic POST AI analysis using price data only
/api/analysis/with-options POST AI analysis with options chain
/api/orders/buy/market POST Place market buy order
/api/orders/buy/limit POST Place limit buy order
/api/orders/sell/market POST Place market sell order
/api/orders/sell/limit POST Place limit sell order
/api/orders/stoploss POST Place stop-loss order
/api/orders/{orderId}/status GET Check order status
/api/orders/{orderId} DELETE Cancel an order
